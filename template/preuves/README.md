# Preuves

Ajouter uniquement les éléments utiles à une observation du rapport : captures d'écran annotées, extraits de journaux ou détails d'un échange.

Nommage conseillé : `OBS-001-description.png` ou `OBS-001-extrait.md`.

Pour chaque preuve, conserver le filtre ou la commande utilisée, l'horodatage et le numéro de paquet, le flux ou l'UID Zeek. Une capture d'écran doit montrer les champs qui soutiennent la conclusion.

Les fichiers binaires extraits du trafic ne sont pas nécessaires à la structure initiale.
